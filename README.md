# Portfolio graphiste

Une page statique de présentation pour Serge Senghor, orientée design graphique et direction artistique. Le site utilise une mise en page éditoriale, une palette papier/terre cuite et quelques animations CSS pour donner du rythme au portfolio.

## Lancer en local

Le projet ne nécessite ni compilation ni dépendance Node.js.

```bash
python3 -m http.server 8080
```

Ouvrir ensuite `http://localhost:8080/` dans un navigateur.

## Structure

- `index.html` contient la page et les styles du prototype.
- Les polices et les icônes sont chargées depuis Google Fonts.
- Le site est autonome et peut être publié sur n'importe quel hébergement statique.
